Each option below is a different strategy, not just a different colour scheme. Same business, same phone number, same eight services — split up four different ways, with a matching design direction and a clickable prototype for each.

How to read this

Pick the sitemap first — that is the decision that actually matters, because it decides what you write and what Google ranks. The design can be swapped onto any of the four structures afterwards.

What is the same in all four

Contact details and a quote form appear on every page (a separate "Contact" page wastes one of your three slots for a business with one phone number). All four keep: the 0451 083 862 click-to-call, the mailto quote form, the 10% first-job offer, the eight services, the six stones, and the free-quote promise.

  • Mission and values appear in all four — the difference is how much room they get.
  • Trade work appears in all four — as a section in A, C and D, as a whole page in B.
  • Every prototype is static HTML on the existing Vercel setup. No build, no framework, no dependencies.

Before any of these goes live

Each prototype has fields only you can fill in. They are marked PLACEHOLDER in the pages so nothing invented reaches a customer:

  • ABN, licence and public liability cover — trade clients check these first (biggest gap in B).
  • Silica compliance — worth stating explicitly in South Australia.
  • Real reviews, real job names and suburbs — all sample text is currently generic.
  • Photos — every image is still a grey placeholder box, per images/LEIA-ME.txt.
  • Turnaround and pricing — the FAQ in C and the rack in D both have blanks for these.
